# GitHub Repos

Click the panel icon to display a list of clickable GitHub repos and the last commit data and author.
Send a notification when a new commit is registered.

## Settings

- **Repositories**: add repositories in the format `owner/name`.
- **GitHub token (optional)**: GitHub API rate limit allows 60 requests
  per hour. A token raises this to 5000. The token is mandatory for private repositories to show.

## Creating a token

Create a fine-grained token under your Github developper settings.
- The token needs to have the **Contents** and **Metadata** permissions which are read-only permissions.
- It is advised to not check any write permissions.
- The token is stored only in your local applet settings. Do not share it.
